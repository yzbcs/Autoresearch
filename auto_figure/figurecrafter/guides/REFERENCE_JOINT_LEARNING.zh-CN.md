# PDF—图片—PPTX 联合参考学习

2026-10-10：正式生产输入只有目标缺图PDF+n张参考图片。离线学习可看参考完整PDF、图像、PPTX。学习材料不逐案例隐藏回灌到正式生产；工具不根据生产参考图片hash检索对应PDF/PPTX/逐样本语义解读。

## 学习目标与匹配对

值得事先构建匹配对。一个学习单元是完整论文PDF及其版本、PDF内某幅图/子图、对应参考图片、原生PPTX与其实际渲染，以及模型解读。文件存在只是候选三元组。模型先核对图号、PDF页码、图注、裁剪范围、内容和native重建差异；目录figure标签可能与PDF不一致。损坏、错配、部分缺失或重建失真保留说明，不能悄悄当正确teacher。ground truth文件是参考证据，不能认为每个字体、科学细节和native重建都无错。

图像中的信息不都等于style：原子颜色、mask区域、实体身份、正负状态可能编码科学含义；字样、人体姿态、临床图像可能是输入/输出或证据；叠片可能表示集合，不能只学“重叠好看”。必须由PDF解释含义，再由对象证据解释如何搭建。反过来用图检验PDF解析是否漏掉条件、操作数、更新边或阶段差异。

## 模型的联合解读流程

1. **匹配核验。** 确认论文版本、实际Figure编号/页码/子图，观察原图和native实际渲染是否一致；记录只存在于原PNG而没有准确重建的部分。
2. **从PDF提取可画的语义。** 聚焦图所覆盖的段落、图注及必要公式；区分方法概览/数据构造/训练/推理/实测证据。形成输入→操作→表示→消费者→条件/监督/更新的关系，列关键出处和歧义；不需要把整篇文字塞进记录。
3. **反向读图。** 指出这些科学实体/边在图中哪个区域，为什么作者在那里展开/并排/重复/省略。解释读图路径、主线与支线、比较结构、视觉焦点、跨区域连接和有效信息密度。用文字说明缺失/压缩的内容，不能捏造“图完整表达了全部PDF”。
4. **解读PPTX的表达程序。** 对关键局部引用native对象ID、名称、归一化bbox、z-order。看shape/freeform/文本/math/image怎样组合，遮挡与叠放何时有意义，fill/stroke/箭头/字体怎样分工。推测的绘制顺序要标“建议重建顺序”，不能把z-order声称成作者真实编辑历史。不照搬未知含义的装饰。
5. **建立局部对齐。** 每条记录包含：科学主张+PDF出处 → 图中视觉表示 → native对象集合/组合 → 为什么放在那里/用这种表征 → 可迁移条件和不可迁移内容。很多对很多对齐，不强迫一句话对应一个shape；科学过程、视觉阅读结构与OOXML对象树是不同层。
6. **形成可复用知识。** 抽象表达选择原则、对象组合的适用条件和失败案例。例如“两个相同阶段结构用并排/重复突出mask变化”，不是“所有主图三栏”；“强轮廓配浅填充保留模块分辨”，不是固定红蓝模板。正文与数学、真实图像与抽象结构、概念矩阵与实测chart分别学习。保留具体示例，避免重新压成“简洁浅色风格”。
7. **模型校验与人工反馈。** 双向检查：PDF语义是否找得到图/对象，图内重点是否有PDF解释。技术校验只查文件、页码、对象ID，不能证明语义正确。模型自审与人工接受独立记录。修订保留旧解读。

解读JSON只是可引用记录，不是scene编译器、对象模板或自动layout。模型自由写内容和组合，工具只验证引用位置存在。图中的figure label核对和对应真假属于模型判断。

联合解读进一步关注过程连续性与终端阅读：从PDF确认关系及其承接，再定位原图和对象组合如何保留身份、改变状态、连接后续使用；分别正确的局部不得自动视作完整过程。分析展开粒度、重复摘要、面积和实际渲染如何支持读取，而非从PPTX提取一套固定字号。原生重建的溢出或失真保留为反例，通用知识不将它们复制到新图。最终形成模型可执行的判断原则，不附目标专属场景或强制组件。

## 学习与生产的隔离

- **离线学习**：完整参考PDF+原PNG+PPTX+实际渲染→模型联合解读库→人工反馈→整理跨样本通用经验；可作为将来训练/评测的有出处数据。目前没有微调模型权重，也没有自动学习器。
- **正式生产**：目标缺图PDF+参考图片→模型解析目标科学语义与图片视觉语言→迁移适合的布局/表征→原生绘制→真实渲染自审→人工评价。参考PDF/PPTX和逐样本teacher解读不作为这个推理输入。
- **知识载体**：当前是模型会话理解、通用学习指南和审查准则。每样本联合解读存离线库；若未来要把库做检索增强输入，必须另定义实验协议，不能仍称“参考只有图片”。跨样本泛化效果须新生产实验验证。
- **匹配对与评测切分**：训练/学习样本和未见目标按论文身份划分，同论文不同图/版本防止跨split；已有看过的目标不能称未见。固定目标PDF并更换图片观察风格响应，另固定图片更换PDF观察科学/布局适配。技术指标与模型/人工评价分别记录，不给自动审美总分。

## 实现入口

`python -m harness.reference_learning catalog --dataset drawing_dataset --out experiments/REFERENCE_LEARNING/catalog.json`
只建候选三元组索引，待模型核验。

`python -m harness.reference_learning prepare --sample drawing_dataset/SAMPLE --root experiments/REFERENCE_LEARNING/SAMPLE`
制作不可覆盖的学习包：PDF/PNG/PPTX/metadata、paper-text、native证据、真实渲染、指南、哈希；不自动找figure页或解释科学语义。

`python -m harness.reference_learning record --root experiments/REFERENCE_LEARNING/SAMPLE --annotation MODEL_INTERPRETATION.json`
保存模型填的图号/页码核验、论文解析、style/layout分析和局部语义—对象对齐。引用ID/页码和字节一致性被检查；模型判断只记录为attestation，human_acceptance保持pending。

生产入口`model_led_drawing prepare`默认production，只接受参考图片；拒绝参考PPTX/native companion。历史复查用显式`--mode legacy-reference-inspection`，不称正式生产。旧已准备输入和历史输出不改写。
