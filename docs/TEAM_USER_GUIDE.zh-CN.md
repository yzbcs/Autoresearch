# AutoResearch 科研平台使用指南

更新日期为 2026 年 11 月 12 日，适用于当前团队服务器的电脑浏览器访问方式。

## 1. 使用前准备

准备好浏览器、可以执行 `ssh` 的终端，以及本人电脑上的代理软件。macOS 可使用“终端”，Windows 可使用 PowerShell。

1. 开启本机代理软件，选择能够访问 ChatGPT 的节点。
2. 在代理软件设置中查看 **HTTP 或 Mixed（混合）代理端口**。下方命令以 `7890` 为例。
3. 向平台维护者获取服务器的 SSH 登录凭据。

| 登录环节 | 凭据来源 |
| --- | --- |
| SSH 连接服务器 | 维护者提供的服务器密码，或已配置的 SSH 密钥 |
| 登录 AutoResearch 网页 | 自己注册的平台用户名和密码 |

科研运行环境与 Codex 登录由服务器维护者配置。

## 2. 在自己的电脑建立 SSH 连接

在本机终端复制并运行下面这一整行命令。

```bash
ssh -N -S none -p 54025 -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:18760:127.0.0.1:8760 -R 127.0.0.1:0:127.0.0.1:7890 root@connect.westd.seetacloud.com
```

**将末尾的 `7890` 改为本人电脑实际的 HTTP 或 Mixed 代理端口。**例如，本机代理端口为 `7897` 时，将对应参数改成

```text
-R 127.0.0.1:0:127.0.0.1:7897
```

| 参数 | 含义 |
| --- | --- |
| `54025` | 当前服务器 SSH 端口 |
| `18760` | 本机浏览器访问平台的端口 |
| `8760` | AutoResearch 在服务器上的服务端口 |
| `-R` 中的 `0` | 由 SSH 自动分配服务器反向转发端口，成员之间无需协调端口 |
| `7890` | 本人电脑的代理端口，按实际设置填写 |
| `-S none` | 为本次访问建立独立 SSH 连接 |

首次连接如果出现主机指纹提示，请与维护者核对后确认。需要输入服务器密码时，输入维护者提供的 SSH 密码，输入过程中屏幕通常没有字符回显。

连接成功后，终端可能显示 `Allocated port` 提示，随后持续保持运行。`-N` 会让 SSH 专门维持转发通道，这时可以直接打开浏览器。

**使用期间保持这个终端和本机代理软件在线。**

## 3. 打开平台网页

在运行上述 SSH 命令的同一台电脑上，用浏览器打开

**[http://127.0.0.1:18760/](http://127.0.0.1:18760/)**

每位成员都在自己的电脑上建立 SSH 连接，并访问这个相同的本地网址。`127.0.0.1` 指浏览器所在的电脑。

## 4. 注册或登录账号

### 首次使用

1. 在登录页点击“注册账号”。
2. 填写用户名、密码和确认密码。
3. 提交后进入自己的科研工作空间。

账号规则如下。

| 项目 | 要求 |
| --- | --- |
| 用户名 | 3～32 个字符，支持字母、数字、下划线、点和连字符，首位为字母或数字 |
| 密码 | 6～128 个字符 |
| 新账号的项目 | 从空的独立项目空间开始 |

### 已有账号

填写自己的平台用户名和密码，点击“登录”。需要修改密码或退出登录时，使用页面右上角的账号菜单。

管理员账号 `admin` 已接管平台原有科研项目。管理员可以在“账号管理”中管理成员、重置密码及调整注册开关。

## 5. 测试本机代理与 Codex 连接

登录后，点击右上角账号菜单，打开“本机代理连接”，再点击“测试 Codex 连接”。

| 页面提示 | 操作 |
| --- | --- |
| 已识别当前 SSH 代理隧道 | 点击测试，确认真实模型调用可用 |
| 正在验证 Codex 模型与命令工具 | 等待模型执行并返回结果 |
| Codex 模型与命令工具调用成功 | 可以进入科研模块使用 |
| 出现错误信息 | 根据提示检查代理、SSH 连接或模型服务状态 |

测试会调用服务器上的真实 Codex，并校验它执行命令后读出的随机文件内容。2026 年 11 月 12 日的一次实测耗时约 **42 秒**。等待时间会受到网络与模型服务负载影响。

Codex 测试设有 **300 秒**调用超时。等待时可以关闭弹窗，稍后重新打开读取结果。关闭弹窗后，服务器会继续执行已经启动的测试。

## 6. 开始科研任务

### 选择需要的模块

| 模块 | 主要用途 |
| --- | --- |
| Auto Search | 围绕研究方向检索论文、调研问题和生成研究思路 |
| Auto Design | 设计实验、推进代码执行与结果分析 |
| Auto Writing | 整理论文内容、调研引用和生成论文工程 |
| Auto Table | 根据数据或论文材料生成、替换科研表格 |
| Auto Figure | 基于论文和参考材料生成、插入科研主图 |

可以直接进入某个模块，也可以在工作台点击“新建全流程”，按页面选择起点、填写研究方向或提交已有材料。

### 查看和继续任务

1. 在对应模块或全流程任务页查看当前状态与日志。
2. 遇到等待补充材料、参考图选择或审核确认时，按页面提示完成操作。
3. 需要设置工作目录时，使用页面给出的服务器账号工作空间。
4. 需要的产物通过任务页面提供的下载入口取回。

账号分别管理各自的科研项目。Codex 登录身份、调用额度和服务器计算资源由平台统一提供，团队成员按约定安排计算任务。

## 7. 本机代理如何供任务使用

平台会自动识别当前网页请求所属的 SSH 连接。

```text
本人浏览器 → 本机 18760 端口 → SSH → 服务器 AutoResearch
服务器 Codex → 发起任务的 SSH 反向隧道 → 本人电脑的代理 → ChatGPT
```

甲和乙分别在自己的电脑运行连接命令后，各自发起的任务使用各自电脑的代理。同一个平台账号从不同 SSH 连接发起任务时，也按发起任务的连接选择代理。

后台任务会继续使用发起时的 SSH 连接。自动跨模块交接的流程会沿用该连接。

## 8. 断线、重连与结束使用

### SSH 或本机代理中断

原有任务记录与已生成文件保存在服务器。后续模型请求会失去原连接的代理，任务可能显示失败或等待恢复。

1. 重新开启本机代理。
2. 在本机终端重新执行第 2 节的完整 SSH 命令。
3. 打开平台网址并登录。
4. 进入原任务，根据页面状态点击“继续”或“重试”。

重新连接并继续任务后，后续调用使用新的 SSH 连接。

### 结束本次使用

根据需要在任务页暂停或停止当前流程，再在 SSH 终端按 `Ctrl+C` 关闭连接。

退出网页账号后，后台任务仍可能继续执行。需要继续调用模型的后台任务依赖发起时的 SSH 隧道与本机代理在线。

## 9. 常见问题

### SSH 命令运行后终端一直停在那里

`ssh -N` 会持续维持转发连接。终端保持运行时，在同一台电脑的浏览器打开平台网址即可。

### 浏览器打不开平台

确认 SSH 终端仍在运行，并核对输入的完整网址为 `http://127.0.0.1:18760/`。如果终端已经退出，先查看终端错误并重新建立连接。

### 提示 `Address already in use`

检查本机是否已有 SSH 隧道占用 `18760`。可以在旧连接的终端按 `Ctrl+C` 关闭旧隧道后重连。

需要同时保留旧连接时，将命令中的

```text
-L 127.0.0.1:18760:127.0.0.1:8760
```

改成

```text
-L 127.0.0.1:18761:127.0.0.1:8760
```

这条新连接的浏览器访问地址随之改为 **[http://127.0.0.1:18761/](http://127.0.0.1:18761/)**。

### 提示需要包含 `-R` 的 SSH 命令

使用第 2 节的完整命令，确认包含 `-R 127.0.0.1:0:127.0.0.1:7890`，并将 `7890` 对应到本人实际的代理端口。

### 出现 `407` 或代理连接失败

检查本机代理是否开启，HTTP 或 Mixed 端口是否填写正确，并检查代理节点与认证设置。调整后重新建立 SSH 连接，再测试 Codex。

### “正在测试”显示了一段时间

测试会等待真实模型运行。可以稍等，也可以关闭弹窗后重新打开读取结果。如果长时间没有变化，向维护者提供发生时间和页面截图，以便核对服务器日志。

### 出现 `Selected model is at capacity`

该提示表示所选模型当前容量受限。可以稍后重试，并向维护者反馈发生时间。2026 年 11 月 12 日的图片模型调用复验曾遇到这一情况。

### SSH 提示连接被拒绝或无法建立连接

请维护者确认服务器实例状态及最新 SSH 地址、端口。本文记录的当前 SSH 端口为 `54025`。

### 手机能直接打开这个本地网址吗

`127.0.0.1` 指当前设备。本文的电脑 SSH 转发在建立隧道的电脑上生效，手机访问入口需要维护者另行配置。

## 10. 问题反馈

联系维护者时，提供以下信息，便于定位。

- 平台用户名。
- 问题发生的北京时间。
- 页面错误原文或截图。
- SSH 终端中的相关错误提示。
- 本机使用的 HTTP 或 Mixed 代理端口。
- 出问题的模块、任务名称和当时执行的操作。

截至本指南更新时，服务器已完成真实 Codex 文本与命令调用验证，独立绘图 Python 环境及 PPTX 转 PDF、PNG 渲染已恢复。图片模型的连接复验仍有容量受限记录，使用时根据实际返回状态处理。
